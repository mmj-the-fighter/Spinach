Step 1: 
Install Visual Studio
Install CMake 3.27 or greater

Step 2:  
Install IntelliJ IDEA for Java
Install Java 17 or greater
Set JAVA_HOME to Java root directory
Add Path variable with Java bin path

Step 3:
Make folder for Ramanujan Computing, Go there through Cmd

Step 4: Building
Open Windows Powershell in administrator mode: 
Set-ExecutionPolicy Unrestricted -Scope Process
git clone https://github.com/Ramanujan-Computing/Ramanujan.git
.\projectBuilder.ps1
During this the console will ask for a workspace directory path
After building copy developer-console-1.0-SNAPSHOT-fat.jar and native.dll to the workspace directory
Make a text file with the following content:

@echo off
java -jar developer-console-1.0-SNAPSHOT-fat.jar %*

Save it as rjc.cmd and place it in workspace directory.

Make system variable called RAMANUJAN_WS with the workspace directory path

Step 5: Run Locally
In workspace directory, execute these commands
rjc homelab 8888

In a separate shell:
rjc worker http://127.0.0.1:8888 8

Build Spinach part
Run distributed_raytracing_for_rjc example

Step 6: Run 4 workers locally and 4 workers in another computer in LAN
In workspace directory, execute these commands
rjc homelab 8888

In a separate shell:
rjc worker http://127.0.0.1:8888 4

In a separate shell:
ipconfig
note down the ip address of the machine

in a second PC on the LAN
copy workspace folder containg rjc.cmd, developer-console-1.0-SNAPSHOT-fat.jar, and native.dll 
Make system variable called RAMANUJAN_WS with the workspace directory path

rjc worker http://thenotedipaddress:8888 4

In the first PC:
Build Spinach part
Run distributed_raytracing_for_rjc example

It is expected that the distributed_raytracing_for_rjc outputs the png image intact.
